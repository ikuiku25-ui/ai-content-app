# 愛知の鉄道3D路線図

名古屋市営地下鉄と、愛知県内の JR東海・名鉄・近鉄の全路線・全駅を、実際の地理座標にもとづく3Dで表示する。
サーバー側の処理は不要で、このフォルダをそのまま静的に配信すれば動く（GitHub Pages では `…/aichi-rail/`）。

- `index.html` … 3D本体
- `preview2d.html` … 位置確認用の平面表示

## 設定ファイル（config/）

書き換えてページを再読み込みすれば反映される（データの作り直しは不要）。

| ファイル | 内容 |
|---|---|
| `layers.json` | 地下鉄の路線ごとの深さ、地上線の事業者ごとの高さ、新幹線（高架）の高さ。表示用の値（m） |
| `underground.json` | 地下鉄以外で地下を走る区間（名鉄名古屋・近鉄名古屋など）。指定した駅を地下に置き、となりの駅まで坂でつなぐ |
| `colors.json` | 路線色・事業者色、同じ事業者の路線どうしの明るさの差 |
| `transfer-groups.json` | 乗換グループ。同名駅の自動まとめの距離と、駅名が違う乗換駅の対応表 |
| `major-stations.json` | 駅名を常に表示する主要駅の決め方と、個別の追加・除外 |

## データ（data/）

`tools/aichi-rail/` の前処理で作る。出典：国土交通省「国土数値情報（鉄道データ・行政区域データ）」を加工して作成。
現在のデータは N02-25（令和7年度）と N03-20260101（令和8年）。
