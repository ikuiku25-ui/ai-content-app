# 愛知の鉄道3D路線図：前処理

国土数値情報の「鉄道（N02）」と「行政区域（N03）愛知県」から、表示用の軽量JSON（`ai-content-app/aichi-rail/data/`）を作る。

```sh
pip install -r requirements.txt
python fetch.py            # 取得（接続できない環境では --n02-zip / --n03-zip で手元の zip を渡す）
python inspect_raw.py      # 属性の一覧。extract.json の値はこれを見て決める
python build.py            # 抽出・県境で切り取り・簡略化・出力（県外の駅が残っていたら失敗する）
python report.py > report.md   # 事業者別・路線別の駅数と乗換グループの一覧
```

- 元データ（`data-raw/`）はリポジトリに入れない。
- 深さ・色・乗換グループなど表示の設定は `ai-content-app/aichi-rail/config/` にあり、ブラウザが読む（ここを直しても build.py の再実行は不要）。
- 現在の出力は N02-25（令和7年度）と N03-20260101（令和8年）から作ったもの。

## 実データで確認した属性（extract.json）

| データ | 属性 | 内容 |
|---|---|---|
| N02 | `N02_004` | 運営会社。地下鉄は「名古屋市」（「名古屋市交通局」ではない） |
| N02 | `N02_003` | 路線名。地下鉄は「1号線東山線」のように番号付き。名城線は「2号線名城線」「4号線名城線」に分かれている |
| N02 | `N02_005` / `N02_005g` | 駅名 / 駅グループコード（同名駅のみをまとめる） |
| N02 | `N02_002` | 事業者種別（1 新幹線、2 JR在来線、3 公営、4 民営） |
| N03 | `N03_004` | 市郡名（名古屋市は区ごとに19件） |
